# 🕵️ Spyware — Caveman Style

**Section:** Malware & Email Security &nbsp;·&nbsp; **Topic:** 70 of 290 &nbsp;·&nbsp; **Level:** 🟢 Beginner

**Spyware** is malware that **secretly watches what a user or computer is doing and collects information without the user's knowledge or permission.**

Think:

> 🪨 Grog is using his computer normally.<br>
> But a tiny invisible spy is hiding behind the rock. 🕵️<br>
> It watches Grog and secretly sends information to the attacker.

```
👤 Grog
   ↓
💻 Computer
   ↓
🕵️ Spyware
   ↓
📡 Secretly sends information
   ↓
👤 Attacker
```

---

# 🎯 The Key Exam Idea

> **Spyware = secretly monitors and collects information.**

The word to remember is:

> 👀 **WATCH**

---

# 🧠 What Can Spyware Collect?

Depending on the spyware, it may collect things such as:

- 🌐 Browsing activity
- 🔑 Credentials
- 📋 Personal information
- 📧 Emails/messages
- 📁 Sensitive files
- 🖥️ System information
- ⌨️ Keystrokes

The goal is usually:

> **Collect information secretly.**

---

# ⌨️ Keylogger = A Type of Spyware

A **keylogger** **records what the victim types**.

For example:

```
👤 User types:

username: Grog
password: Secret123

        ↓

⌨️ Keylogger
        ↓
🕵️ Attacker receives it
```

So:

> 🕵️ **Spyware = broader category**

> ⌨️ **Keylogger = specifically records keystrokes**

A keylogger can therefore be used as a **form of spyware**.

---

# 🆚 Spyware vs Ransomware

### 🕵️ Spyware

> **Secretly watches/collects information.**

```
👤 → 💻 → 🕵️ → 📡 → 👤 Attacker
```

### 🔒 Ransomware

> **Locks/encrypts data and demands payment.**

```
📁 Data
  ↓
🔒 Locked
  ↓
💰 Pay
```

<p align="center"><img src="diagrams/2.svg" alt="diagram"></p>

### 🧠 Memory:

> 🕵️ **Spyware = steal information**

> 🔒 **Ransomware = lock information**

# 🆚 Spyware vs Keylogger

| | 🕵️ Spyware | ⌨️ Keylogger |
| --- | --- | --- |
| Main idea | Secret monitoring/collection | Records keystrokes |
| Scope | Broad | Specific |
| Can capture passwords? | ✅ | ✅ |
| Can monitor browsing? | ✅ | ❌ Not necessarily |
| Keylogger can be spyware? | — | ✅ |

### Exam trick:

> **"Records everything the user types."** → ⌨️ **Keylogger**

> **"Secretly monitors/collects user information."** → 🕵️ **Spyware**

---

# 🆚 Spyware vs Trojan

These describe **different things**.

### 🐴 Trojan

> **How the malware tricks the victim into installing/running it.**

### 🕵️ Spyware

> **What the malware is trying to do: secretly monitor/collect information.**

They **can occur together**:

```
🎮 Fake application
       ↓
🐴 Trojan
       ↓
🕵️ Spyware
       ↓
🔑 Stolen information
```

**A Trojan could deliver spyware.**

---

# 🆚 Spyware vs Virus

### 🦠 Virus

> **Attaches** to files/programs and replicates.

### 🕵️ Spyware

> **Secretly monitors and collects information.**

They are **not the same thing**.

---

# 🎯 Exam Scenarios

### Scenario 1

> Malware secretly records a user's browsing activity and sends the information to an attacker.

→ 🕵️ **Spyware**

### Scenario 2

> Malware records every key the user presses.

→ ⌨️ **Keylogger**

### Scenario 3

> Malware encrypts company files and demands payment.

→ 🔒 **Ransomware**

### Scenario 4

> Malware disguises itself as a legitimate application.

→ 🐴 **Trojan**

### Scenario 5

> Malware automatically copies itself across vulnerable systems.

→ 🪱 **Worm**

When you see **"Secretly monitors"**, **"Secretly collects information"** or **"Tracks user activity"** → 🕵️ **SPYWARE**

> ⌨️ **Keylogger = records typing**

## 🧪 Quick Check

**1. What is spyware?**
<details><summary>Answer</summary>Malware that secretly monitors a user or system and collects information without the user's knowledge or permission.</details>

**2. What single word defines spyware?**
<details><summary>Answer</summary>Watch — secret monitoring and collection.</details>

**3. Name four kinds of information spyware may collect.**
<details><summary>Answer</summary>Any four of: browsing activity, credentials, personal information, emails/messages, sensitive files, system information, keystrokes.</details>

**4. What is the relationship between spyware and a keylogger?**
<details><summary>Answer</summary>Spyware is the broad category; a keylogger is a specific type that records keystrokes and can be used as spyware.</details>

**5. Malware silently sends a user's visited websites and saved passwords to a remote server, while the PC keeps working normally. What is it?**
<details><summary>Answer</summary>Spyware.</details>

**6. How does spyware differ from ransomware in what it wants the victim to notice?**
<details><summary>Answer</summary>Spyware wants to stay unnoticed while it steals information. Ransomware wants to be noticed — it locks the data and demands payment.</details>

**7. A "free wallpaper app" installs software that secretly tracks the user. Is it a Trojan or spyware?**
<details><summary>Answer</summary>Both — the Trojan is how it got in (disguise); spyware is what it does (secretly monitor).</details>

**8. Why is spyware especially dangerous even though nothing seems wrong?**
<details><summary>Answer</summary>Because it's silent: stolen credentials and data can be used for account takeover, fraud or further attacks long before anyone realizes the system was compromised.</details>
